# MÓDULO 1: FUNDAMENTOS
## Capítulo 3 - Como Conversar com uma IA

---

## 💬 O que é Prompt?

**Prompt = A instrução que você dá à IA**

Um bom prompt gera respostas úteis. Um prompt ruim gera respostas genéricas.

---

## 🏗️ Estrutura Básica

Use esta fórmula:

1. **Contexto** - Qual é a situação?
2. **Objetivo** - O que você quer?
3. **Público** - Para quem é?
4. **Restrições** - Qual é o tom? O que evitar?
5. **Formato** - Como deve aparecer?

---

## ❌ VS ✅ Fraco x Forte

### ❌ FRACO
```
"Faça um post sobre marketing."
```
**Problema:** Genérico, sem contexto, sem objetivo claro.

### ✅ FORTE
```
"Crie 5 ideias de posts para uma marca de beleza que vende para 
mulheres de 25-40 anos interessadas em sustentabilidade. 
Use tom acolhedor, amigável e com foco em autoridade. 
Cada post deve ter: título, objetivo e exemplo de legenda."
```
**Vantagem:** Específico, contextuado, objetivo claro.

---

## 📊 Comparação Visual

| Aspecto | Prompt Fraco | Prompt Forte |
|---------|-------------|---------------|
| **Contexto** | Ausente | Bem definido |
| **Objetivo** | Vago | Específico |
| **Público** | Não mencionado | Detalhado |
| **Resultado** | Genérico | Útil |
| **Qualidade** | Baixa | Alta |
